Проверка товара

Покажет, куда приложение положит товар по словарю. Личная история человека (его прошлые правки) здесь не учитывается.

Правила

Срабатывает первое подходящее правило: сначала по первому слову названия, потом по всему названию. Ключ «=слово» — только точное слово, без «=» — начало слова.

Признаки общепита

Если одно из этих слов есть в названии магазина, товары с правилами для «Продуктов» уходят в «Кафе и рестораны», а у правил с вариантом «в рознице» берётся основной вариант.

Выпуск

Лист показывается один раз на каждый новый идентификатор. Поправили опечатку — оставьте прежний. Хотите, чтобы все увидели снова, — «Новый выпуск».

Пункты

2–4 пункта читаются лучше всего.

Так увидят

Иконка в приложении будет настоящая — здесь только цвет.

Доступ к публикации

Читать файлы можно без токена. Чтобы публиковать, нужен токен GitHub с правом записи только в этот репозиторий. Он хранится только в этом браузере.

Как получить токен (один раз)

  1. Откройте github.com/settings/personal-access-tokens/new.
  2. Token name: SkarbIQ editor. Expiration: 1 год.
  3. Repository access: Only select repositories → diman9999/skarbiq.
  4. Permissions → Repository permissions → Contents: Read and write. Остальное не трогайте.
  5. Generate token, скопируйте и вставьте сюда. На каждом устройстве — один раз.

Если токен утечёт, им можно только менять файлы этого сайта. Отозвать его — там же, в настройках GitHub.
